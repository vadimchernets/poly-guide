电脑路径区分了：打开工作环境、检查已登录的文件访问权限，以及经这个人确认的第一个真实结果。在此之后，受支持的主导工具 Claude Code/Codex 可以使用另一个已安装的命令行工具，并在同一个窗口里收到它实际的检查输出。Poly 准备任务；它不执行也不检查那个终端。手机版 Duo 是外部的，并取决于平台；打开它的快捷指令并不能证明有结果。

针对两种电脑工具的设置、首次任务和单窗口消息，与完整的核心指令一起，直接由应用生成。源函数和每个文件的 SHA-256 请见 `prompts/index.json`。发布软件包是所有者的操作，而不是生成它的副作用。

这个 `a2/` 目录是一个追加式的发布包。它不会取代此仓库中的其他材料。外部服务的功能，取决于实际的账号、设备、地区和权限。不承诺无限使用、永久记忆、自动控制终端，或应用商店发布。
