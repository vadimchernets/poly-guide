Перевірено: 2026-11-05. Це посилання на документацію постачальників і репозиторії проєктів, а не доказ того, що в акаунті конкретної людини функцію ввімкнено. ## Супутні проєкти Poly A2

Перед описом сумісності з хостом чи налаштування прочитайте кожен актуальний репозиторій. Це незалежні проєкти з відкритим кодом, а не інтеграції, схвалені постачальниками, і Poly A2 не встановлює їх непомітно.

- https://github.com/vadimchernets/sidecall — Claude Code звертається до наявних інструментів ШІ командного рядка й порівнює їхні твердження. README репозиторію отримано через публічний API репозиторіїв GitHub у дату перевірки.
- https://github.com/vadimchernets/roundcall — порівняння через наявні сайти чатів із ШІ в Chrome людини та Claude in Chrome; воно не визначає істину й не виконує безперервних фонових раундів.
- https://github.com/vadimchernets/pocketcall — підготовка до безнаглядної роботи комп'ютера та стисле спілкування для телефона, а не саме віддалене з'єднання.
- https://github.com/vadimchernets/calling-kits — відібрані робочі процеси Claude Code для окремих покликань, матеріали профілю, приклади та перевірка джерел.

## Стан публікації та локального прототипу

Попередня перевірка перед завантаженням виявила, що цілі нового основного посібника недоступні. Пізніше власник повідомив, що опублікував попередній пакет. Створення цього оновленого пакета перевіряє лише цілісність локальних байтів; воно не підтверджує, що остання редакція вже в мережі:

- https://polyhelper.ai/g/a2.md
- https://raw.githubusercontent.com/vadimchernets/poly-guide/main/a2/guide.md

Власник або співпрацівник із публікації завантажує оновлення та перевіряє відповіді HTTP, вміст і хеші. Генератор не публікує й не замінює вміст репозиторію віддалено. Локальні збірки для мобільних пристроїв/комп'ютера, налаштування магазину, успішна зовнішня робота й синхронізація акаунтів потребують окремих доказів. Невелика локальна панель для Mac не виконує й не читає інший термінал, а ручні картки не є автоматичною синхронізацією телефона й комп'ютера.
