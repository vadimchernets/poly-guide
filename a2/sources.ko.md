# Poly A2 — 출처 목록

확인일: 2026-11-05. 이것은 제공업체 문서와 프로젝트 저장소에 대한 참고 링크일 뿐, 특정 사용자의 계정에서 기능이 켜져 있다는 증거가 아니에요. 요금제, 단계적 제공, 지역, 사용 한도, 모델, 권한, 화면은 바뀌어요. 설정이나 구매를 조언하기 전에 해당 공식 페이지를 다시 여세요.

## Poly A2 동반 프로젝트

호스트 호환성이나 설정을 설명하기 전에 각 현재 저장소를 읽으세요. 이것들은 독립적인 오픈소스 프로젝트이며, 제공업체가 보증한 연동이 아니고 Poly A2가 몰래 설치하지도 않아요.

- https://github.com/vadimchernets/sidecall — Claude Code가 기존 AI 명령줄 도구에 의견을 구하고 그 주장을 비교해요. 저장소 README는 확인일에 GitHub 공개 저장소 API로 가져왔어요.
- https://github.com/vadimchernets/roundcall — 사용자의 Chrome과 Claude in Chrome에서 기존 AI 채팅 웹사이트를 통해 비교해요. 무엇이 사실인지 판단하거나 계속 백그라운드 라운드를 돌리지는 않아요.
- https://github.com/vadimchernets/pocketcall — 사람이 지켜보지 않는 컴퓨터 작업과 휴대폰에서 볼 간결한 소통을 준비해요. 원격 연결 자체는 아니에요.
- https://github.com/vadimchernets/calling-kits — 선별된 소명별 Claude Code 작업 순서, 프로필 자료, 예시, 출처 확인.

## 공개 및 로컬 시제품 상태

이전의 업로드 전 확인에서는 새 기준 안내의 대상 주소들을 쓸 수 없었어요. 이후 소유자가 이전 패키지를 공개했다고 알렸어요. 이 업데이트된 패키지를 생성하는 것은 로컬 바이트 무결성만 확인할 뿐, 최신 개정판이 이미 온라인에 있다는 것을 확인하지는 않아요.

- https://polyhelper.ai/g/a2.md
- https://raw.githubusercontent.com/vadimchernets/poly-guide/main/a2/guide.md

소유자나 공개 협업자가 업데이트를 올리고 HTTP 응답, 내용, 해시를 확인해요. 생성기는 저장소 내용을 원격으로 공개하거나 바꾸지 않아요. 모바일/데스크톱 로컬 빌드, 스토어 설정, 성공적인 외부 작업, 계정 동기화는 각각 별도의 증거가 필요해요. 작은 로컬 Mac 패널은 다른 터미널을 실행하거나 읽지 않으며, 직접 쓰는 카드는 자동 휴대폰/컴퓨터 동기화가 아니에요.
