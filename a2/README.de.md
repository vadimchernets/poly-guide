# Poly A2

Jetzt helfen, durch nützliche Arbeit wachsen. Beginnen Sie in der KI, die eine Person schon nutzt, fügen Sie eine in sich geschlossene Poly A2 Anweisung ein und setzen Sie die echte Aufgabe der Person fort. Die Anleitung ist ein Nachschlagewerk für die unterstützende KI, kein vorgeschriebener Kurs und kein Grund, jede Antwort in eine App zurückzuschicken.

Der Computer-Weg unterscheidet das Öffnen der Arbeitsumgebung, die Prüfung des Dateizugriffs bei angemeldetem Konto und ein erstes echtes Ergebnis, das die Person bestätigt. Danach kann eine unterstützte leitende KI (Claude Code/Codex) das andere installierte CLI nutzen und dessen tatsächliche Prüfausgabe im selben Fenster erhalten. Poly A2 bereitet den Auftrag vor; es führt dieses Terminal weder aus noch prüft es es. Duo auf dem Handy ist extern und plattformabhängig; das Öffnen seines Kurzbefehls beweist kein Ergebnis.

Nachrichten für Einrichtung, erste Aufgabe und Ein-Fenster-Betrieb für beide Computerwerkzeuge werden direkt aus der Anwendung neben den vollständigen Kernanweisungen erzeugt. Siehe `prompts/index.json` für Quellfunktionen und SHA-256 je Datei. Das Veröffentlichen des Pakets ist eine Handlung des Eigentümers, keine Nebenwirkung seiner Erzeugung.

Dieses Verzeichnis `a2/` ist ein ergänzendes Veröffentlichungspaket. Es ersetzt kein anderes Material in diesem Repository. Funktionen externer Dienste hängen von Konto, Gerät, Region und Berechtigungen ab. Es werden keine unbegrenzte Nutzung, kein dauerhaftes Gedächtnis, keine automatische Terminal-Steuerung und keine Veröffentlichung im App Store versprochen.
