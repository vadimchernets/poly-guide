# Poly A2

いますぐ助け、役に立つ作業を通じて成長する。その人がすでに使っているAIで始め、単独で使えるPoly A2のプロンプトを貼り付けて、その人の本当のタスクを続けます。このガイドは、手伝うAIのための参照であり、必須のコースでも、すべての答えをアプリに戻す理由でもありません。

パソコンの道では、作業環境を開くこと、サインイン済みでファイルにアクセスできることの確認、そしてその人が確認した最初の本当の結果を、区別します。そのあと、対応する主担当のClaude CodeやCodexは、もう一方のインストール済みCLIを使い、その実際の確認の出力を同じウィンドウで受け取れます。Poly A2は依頼を用意するだけで、そのターミナルを実行したり点検したりはしません。スマホのDuoは外部のもので、プラットフォームに依存します。そのショートカットを開いただけでは、結果の証明にはなりません。

両方のパソコンツール向けの、設定、最初のタスク、1つのウィンドウのメッセージは、完全な基本プロンプトとともに、アプリから直接生成されます。ソースの関数とファイルごとのSHA-256は、`prompts/index.json`をご覧ください。パッケージを公開することは、オーナーの操作であり、生成の副作用ではありません。

この`a2/`ディレクトリは、追加の公開パッケージです。このリポジトリのほかの内容を置き換えるものではありません。外部サービスの機能は、実際のアカウント、端末、地域、許可によります。無制限の利用、永続的なメモリ、ターミナルの自動操作、アプリストアでのリリースは、約束されていません。
