## Poly के साथी प्रोजेक्ट

होस्ट की अनुकूलता या सेटअप बताने से पहले हर मौजूदा रिपॉज़िटरी पढ़ें। ये स्वतंत्र ओपन-सोर्स प्रोजेक्ट हैं, प्रदाताओं द्वारा समर्थित एकीकरण नहीं, और Poly इन्हें चुपचाप इंस्टॉल नहीं करता।

- https://github.com/vadimchernets/sidecall — Claude Code का मौजूदा AI कमांड-लाइन टूल से सलाह लेना और उनके दावों की तुलना करना। रिपॉज़िटरी का README जाँच की तारीख पर GitHub की सार्वजनिक रिपॉज़िटरी API से लिया गया।
- https://github.com/vadimchernets/roundcall — व्यक्ति के Chrome और Claude in Chrome में मौजूदा AI चैट वेबसाइटों के ज़रिए तुलना; यह सच तय नहीं करता और लगातार पृष्ठभूमि वाले दौर नहीं चलाता।
- https://github.com/vadimchernets/pocketcall — बिना निगरानी वाले कंप्यूटर काम और फ़ोन के लिए संक्षिप्त संवाद की तैयारी, रिमोट कनेक्शन खुद नहीं।
- https://github.com/vadimchernets/calling-kits — चुने हुए ध्येय-विशेष Claude Code कार्यप्रवाह, प्रोफ़ाइल सामग्री, उदाहरण और स्रोत-जाँच।

## प्रकाशन और स्थानीय प्रोटोटाइप की स्थिति

अपलोड से पहले की एक पुरानी जाँच में नई मान्य गाइड के ठिकाने उपलब्ध नहीं मिले। मालिक ने बाद में बताया कि उन्होंने पहले का पैकेज प्रकाशित किया। यह अद्यतन पैकेज बनाना केवल स्थानीय बाइट की अखंडता जाँचता है; यह पुष्टि नहीं करता कि नवीनतम संस्करण पहले से ऑनलाइन है:

- https://polyhelper.ai/g/a2.md
- https://raw.githubusercontent.com/vadimchernets/poly-guide/main/a2/guide.md

मालिक या प्रकाशन में साथ देने वाला अद्यतन अपलोड करता है और HTTP जवाब, सामग्री और हैश जाँचता है। जनरेटर रिपॉज़िटरी की सामग्री को दूर से न प्रकाशित करता है और न बदलता है। मोबाइल/डेस्कटॉप के स्थानीय बिल्ड, स्टोर सेटअप, बाहरी काम की सफलता और खाता सिंक्रनाइज़ेशन, हर एक को अपना सबूत चाहिए। छोटा स्थानीय Mac पैनल दूसरा टर्मिनल न चलाता है और न पढ़ता है, और हाथ से बने कार्ड फ़ोन/कंप्यूटर का अपने आप सिंक नहीं हैं।
