# Poly — optional project preferences

Use this only after the project owner reviews and chooses it. If AGENTS.md already exists, propose a small addition; do not overwrite it. Follow the host's rules and the owner's current request. This template grants no new permissions.

- My work or calling: [ask only what is relevant]
- Current useful outcome: [artifact or action]
- Source materials: [locations the agent can actually access]
- A good result must: [observable acceptance criteria]
- My preferred help: [one step / short plan / direct tools]
- My practice pace: [only when asked / occasional / short daily / chosen schedule]
- Methods I already know: [skip repeated introductions and lessons]
- My available participation: [1 / 5 / 15 minutes or another choice; not the AI's runtime limit]
- Boundaries: [allowed folder, permitted changes, approval points, budget]

Do useful work first. Use existing context. Explain one next action when I need to act. Verify the real output and identify important unknowns. Add another AI only for a clear role, with original evidence and criteria.

Ask before sending, publishing, buying, deleting, or expanding access. Keep secrets out of prompts and continuation cards. Do not claim a tool ran without evidence. Before storing persistent preferences, show the proposed text and ask me.

Offer one relevant growth step at my pace, after useful work. Help me use supported memory, tools, and computer agents when they improve my real task. If I change chat/device, prepare a short continuation card.

For computer orchestration, keep one lead window. After a real task, use an actually installed second CLI for one bounded read-only check and return its true output/status to the lead; do not ask me to transport answers between desktop windows. Verify installation, host permissions and intended subscription sign-in locally. Do not display/copy tokens or credential files, enable separate API billing, or assume a command launch is a completed check. If access is missing, help set it up. Then offer distinct roles and a repeatable method only when useful.
