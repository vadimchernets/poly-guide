# Poly A2

Help now, grow through useful work. Start in the AI a person already uses, paste a self-contained Poly A2 prompt, and continue the person's real task. The guide is a reference for the assisting AI, not a required course or a reason to send every answer back to an app.

The computer route distinguishes opening the working environment, checking signed-in file access, and a first real result confirmed by the person. After that, a supported lead Claude Code/Codex can use the other installed CLI and receive its actual checking output in the same window. Poly A2 prepares the assignment; it does not execute or inspect that terminal. Phone Duo is external and platform-dependent; opening its shortcut does not prove a result.

Setup, first-task and one-window messages for both computer tools are generated directly from the application alongside the full core prompts. See `prompts/index.json` for source functions and per-file SHA-256. Publishing the package is an owner action, not a side effect of generating it.

This `a2/` directory is an additive publication package. It does not replace other material in this repository. External service features depend on the actual account, device, region, and permissions. No unlimited usage, permanent memory, automatic terminal control, or app-store release is promised.

Poly A2 помогает сейчас и растит возможности через полезное дело. Человек открывает привычный ИИ, вставляет самодостаточный промпт и продолжает работу там. Руководство дополняет промпт; недоступность ссылки не блокирует помощь.

Папка `a2/` добавляется к существующему репозиторию. Прежние материалы сохраняются. Промпты выгружаются из кода приложения, руководства сайта и зеркала равны побайтово. Исходники и контрольные суммы обновляются вместе при сборке пакета.

Компьютерный путь: открыть среду → проверить готовность Claude Code/Codex → выполнить настоящее поручение и проверить результат. Далее — второй установленный CLI и настоящий вывод в том же ведущем окне, затем разные роли и повторяемый процесс. На телефоне Duo запускается отдельной поддерживаемой командой; ручная проверка остаётся запасным путём. Полный промпт, настройка и задания выгружаются из функций приложения. Панель Poly A2 сама не выполняет команды и не видит чужие ответы.
