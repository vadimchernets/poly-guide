# Poly

Помогает сейчас и развивает возможности через полезное дело. Откройте привычный ИИ, вставьте готовое сообщение и продолжайте настоящее дело там. Руководство дополняет сообщение. Его не нужно проходить как курс или возвращать каждый ответ в приложение.

Компьютерный путь: открыть среду, войти и проверить работу с файлами, выполнить настоящее дело. Результат проверяет человек. Затем ведущий Claude Code или Codex может вызвать второй установленный CLI. Настоящий вывод проверки приходит в то же окно. Poly готовит поручение, но не выполняет команды и не читает чужой терминал. Poly Duo работает отдельно с учётом устройства. Открытая команда не доказывает полезный результат.

Сообщения настройки, первого дела и двух ИИ собраны из действующих функций приложения. Доступность зависит от страны, аккаунта, подписки, устройства и разрешений. Безграничная работа, вечная память, автоматическое управление терминалом и выпуск в магазинах не обещаны.

Папка a2/ добавляется к существующему репозиторию. Прежние файлы сохраняются. Руководства сайта и зеркала совпадают побайтово. Исходники и контрольные суммы обновляются вместе при сборке пакета.
