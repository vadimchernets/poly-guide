# Poly

Help now, grow through useful work. Start in the AI a person already uses, paste a self-contained Poly prompt, and continue the person's real task. The guide is a reference for the assisting AI, not a required course or a reason to send every answer back to an app.

The computer route distinguishes opening the working environment, checking signed-in file access, and a first real result confirmed by the person. After that, a supported lead Claude Code/Codex can use the other installed CLI and receive its actual checking output in the same window. Poly prepares the assignment; it does not execute or inspect that terminal. Phone Duo is external and platform-dependent; opening its shortcut does not prove a result.

Setup, first-task and one-window messages for both computer tools are generated directly from the application alongside the full core prompts. See `prompts/index.json` for source functions and per-file SHA-256. Publishing the package is an owner action, not a side effect of generating it.

This `a2/` directory is an additive publication package. It does not replace other material in this repository. External service features depend on the actual account, device, region, and permissions. No unlimited usage, permanent memory, automatic terminal control, or app-store release is promised.
