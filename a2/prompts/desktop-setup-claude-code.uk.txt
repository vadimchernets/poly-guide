Poly A2 · Допоможи мені відкрити й підготувати Claude Code на моєму комп'ютері.

Формат доручення для цієї роботи:
1. Мета: одне речення про те, яким буде готовий результат.
2. Матеріали: які саме файли, посилання або нотатки ви використовуєте.
3. Обмеження: чого не можна робити і до чого не можна торкатися.
4. Готово, коли: як ми обоє зрозуміємо, що результат хороший.
Спочатку план: перш ніж щось змінювати чи створювати, покажіть мені план і поставте запитання. У кожного висновку вказано файл, звідки він узятий (з рядком або сторінкою). Наприкінці розділ «Не прочитав упевнено»: усе, що не вдалося відкрити, погано читається або викликає сумнів. Нічого не видаляйте; зайве перемістіть у теку «На перегляд» і повідомте мені.

Спершу врахуй мій наявний доступ і підписки; не відправляй мене купувати їх знову.

Простий шлях: офіційний застосунок Claude для комп'ютера → ваш акаунт → вкладка Code → локальна папка. Окремий термінал для цього шляху не потрібен.

Якщо операційна система мого комп'ютера або встановлений застосунок невідомі, запитай лише про це. Пропусти встановлення, якщо воно вже зроблене. Допоможи мені обрати локальну папку з копіями матеріалів і перевірити, що обраний ШІ справді може з ними працювати.

Для доступу за підпискою використовуй звичайний вхід в обраний сервіс, а не оплату через API-ключ. Не проси мене ділитися паролями, токенами чи ключами. Якщо активний окремий режим оплати, зупинись і допоможи мені перевірити його до початку роботи; не перемикай його й не запускай окремих списань без мого рішення. Підписка Poly A2 не оплачує зовнішній ШІ. Актуальні ціни, можливості й ліміти перевіряй в офіційних умовах.
