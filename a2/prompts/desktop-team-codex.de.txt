Poly A2 · Zwei KI in einem Fenster. Du bist die Leitung Codex; binde Claude Code über das installierte Kommandozeilenwerkzeug auf meinem Computer als unabhängigen Prüfer an.

Auftragsformat für diese Arbeit:
1. Ziel: ein Satz, der sagt, wie das fertige Ergebnis aussieht.
2. Material: genau welche Dateien, Links oder Notizen Sie verwenden.
3. Grenzen: was Sie nicht tun oder anfassen dürfen.
4. Fertig, wenn: woran wir beide erkennen, dass das Ergebnis gut ist.
Erst der Plan: Bevor Sie etwas ändern oder anlegen, zeigen Sie mir Ihren Plan und stellen Sie Ihre Fragen. Jede Ausgabe nennt die Datei, aus der sie stammt (mit Zeile oder Seite). Am Ende ein Abschnitt „Nicht sicher gelesen“: alles, was Sie nicht öffnen oder nicht gut lesen konnten oder bei dem Sie unsicher sind. Löschen Sie nichts; verschieben Sie Überflüssiges in einen Ordner „Zum Prüfen“ und sagen Sie mir Bescheid.

Poly A2 · Erledigen Sie die Aufgabe und prüfen Sie das Ergebnis. Bleiben Sie in diesem Hauptfenster. Bereiten Sie die Dateien vor und führen Sie die Befehle selbst aus. Lesen Sie tools/WORKFLOW.md und suchen Sie tools/workflow.py im Paket. Falls es fehlt, beziehen Sie es über die angegebene manifest.json und prüfen Sie die Datei-Hashes. Nutzen Sie die bereits erlaubte Aufgabe und Texte; fragen Sie nur nach fehlender Erlaubnis. Erstellen Sie daraus task.txt und approved.txt selbst. Falls new-run bereits besteht, wählen Sie einen neuen Ergebnisordner. Führen Sie im Paketordner aus: python3 tools/workflow.py --task-file task.txt --source approved.txt --output new-run --producer codex --reviewer claude-code --max-calls 2 --max-seconds 300 --stop-file STOP-POLY-A2 --allow-network. Bringen Sie beide echten Antworten hierher zurück. Prüfen Sie jede Aussage der prüfenden KI anhand der Originaldatei, eines Zitats, einer Rechnung oder einer beobachtbaren Änderung. Halten Sie angenommene und verworfene Hinweise mit Belegen fest. Beheben Sie nur bestätigte Probleme innerhalb meiner Erlaubnis und prüfen Sie die fertigen Dateien. Zeigen Sie den Speicherort. Verlangen Sie von mir weder Befehle noch das Übertragen von Antworten zwischen Chats. Eine kopierte Nachricht oder die Zustimmung zweier KI beweist keinen Erfolg. Nutzen Sie hier workflow statt eines zusätzlichen review-Aufrufs über den Adapter.

Nach einer echten Aufgabe und einer unabhängigen Prüfung können wir auf mehrere verschiedene Rollen erweitern, dann auf eine wiederholbare Abfolge mit klaren Prüfungen, Abbruchbedingungen und meiner Ausgabengrenze. Starte keine langen oder kostenpflichtigen Läufe ohne meine Entscheidung.
