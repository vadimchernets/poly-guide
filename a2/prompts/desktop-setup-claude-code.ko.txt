Poly A2 · 내 컴퓨터에서 Claude Code을(를) 열고 준비하는 것을 도와주세요.

이 작업의 요청 형식:
1. 목표: 완성된 결과가 어떤 모습인지 한 문장으로.
2. 자료: 사용할 파일, 링크, 메모를 구체적으로.
3. 제한: 하지 말아야 할 일과 건드리지 말아야 할 것.
4. 완료 조건: 결과가 좋다는 것을 우리 둘이 어떻게 확인할지.
먼저 계획: 무엇이든 바꾸거나 만들기 전에 계획을 보여 주고 질문하세요. 모든 결과물에는 출처 파일을(줄 또는 쪽 번호와 함께) 적으세요. 마지막에 “확실히 읽지 못한 것” 항목을 두고, 열지 못했거나 잘 읽지 못했거나 확신이 없는 것을 모두 적으세요. 아무것도 삭제하지 말고, 남는 것은 “검토용” 폴더로 옮긴 뒤 알려 주세요.

먼저 제가 이미 가진 접근 권한과 구독을 확인해 주세요. 같은 것을 다시 사라고 안내하지 마세요.

간단한 방법: 공식 Claude 데스크톱 앱 → 내 계정 → Code 탭 → 로컬 폴더. 이 방법에는 별도의 터미널이 필요하지 않아요.

내 컴퓨터의 운영체제나 설치된 앱을 모르면 그 정보만 물어보세요. 이미 설치되어 있으면 설치 단계는 건너뛰세요. 자료 사본이 담긴 로컬 폴더를 고르고, 선택한 AI가 그 자료로 실제 작업할 수 있는지 확인하도록 도와주세요.

구독으로 이용할 때는 API 키 요금제가 아니라 선택한 서비스의 일반 로그인을 사용하세요. 비밀번호, 토큰, 키를 공유해 달라고 하지 마세요. 별도의 요금 방식이 켜져 있으면 작업 전에 멈추고 확인을 도와주세요. 제 결정 없이 요금 방식을 바꾸거나 별도 요금이 나가게 하지 마세요. Poly A2 구독은 외부 AI의 비용을 대신 내 주지 않아요. 현재 가격, 기능, 한도는 공식 약관에서 확인하세요.
