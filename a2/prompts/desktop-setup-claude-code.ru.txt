Poly · Помоги мне открыть и подготовить Claude Code на моём компьютере.

Формат поручения для этой работы:
1. Цель: одна фраза о том, каким будет готовый результат.
2. Материалы: какие именно файлы, ссылки или заметки вы используете.
3. Ограничения: чего нельзя делать и к чему нельзя прикасаться.
4. Готово, когда: как мы оба поймём, что результат хороший.
Сначала кратко покажите план. Спросите только о недостающем решении или разрешении. Если дело и действия уже согласованы, продолжайте до проверенного результата. У каждого вывода указан файл, откуда он взят (со строкой или страницей). В конце раздел «Не прочёл уверенно»: всё, что не удалось открыть, плохо читается или вызывает сомнение. Ничего не удаляйте; лишнее переместите в папку «На просмотр» и сообщите мне.

Сначала учти мой уже имеющийся доступ и подписки; не отправляй меня покупать их повторно.

Простой путь: официальное приложение Claude на компьютере → вход в свой аккаунт → вкладка Code → локальная папка. Для этого пути отдельный терминал не обязателен.

Если система компьютера или наличие приложения неизвестны, спроси только это. Если всё уже установлено, пропусти установку. Помоги выбрать локальную папку с копиями нужных материалов и убедиться, что выбранный ИИ действительно может с ними работать.

Для доступа по подписке используй обычный вход в аккаунт выбранного сервиса, а не оплату по API-ключу. Не проси присылать пароли, токены или ключи. Если включён отдельный платёжный режим, остановись и помоги проверить его перед работой; не меняй его и не начинай отдельные расходы без моего решения. Подписка Poly не оплачивает внешний ИИ. Текущие цены, включённые функции и лимиты проверяй по официальным условиям.

Актуальное руководство: https://code.claude.com/docs/en/desktop-quickstart
Терминал для тех, кому он нужен: https://code.claude.com/docs/en/quickstart
Вход: https://code.claude.com/docs/en/authentication

Без веба используй описанный путь, но не выдумывай актуальные команды установки. Давай по одному подходящему действию на моём устройстве. Установка считается готовой только когда я открыл(а) рабочую среду и проверил(а) доступ; копирование ссылки этого не доказывает.
