## Другие проекты для Poly A2

Перед советом о совместимости и настройке прочитайте текущий репозиторий. Это независимые открытые проекты. Разработчики ИИ не объявляли их своими подключениями. Poly A2 не устанавливает их незаметно.

- https://github.com/vadimchernets/sidecall — Claude Code обращается к уже установленным ИИ через командную строку и сравнивает утверждения. README получен через открытый API GitHub в указанную дату.
- https://github.com/vadimchernets/roundcall — сравнение ответов в открытых чатах в Chrome человека и Claude in Chrome. Проект не определяет истину и не проводит бесконечные фоновые круги.
- https://github.com/vadimchernets/pocketcall — подготовка самостоятельной работы компьютера и коротких сообщений для телефона. Само удалённое подключение проект не создаёт.
- https://github.com/vadimchernets/calling-kits — подобранные способы работы Claude Code с обращением к другим ИИ, описания интересов, примеры и проверка источников.

## Публикация и местная пробная версия

Раньше перед загрузкой новые основные ссылки руководства не открывались. Позже владелец сообщил о публикации прежнего пакета. Сборка нынешнего пакета проверяет только совпадение местных файлов. Она не доказывает, что последняя версия уже опубликована:

- https://polyhelper.ai/g/a2.md
- https://raw.githubusercontent.com/vadimchernets/poly-guide/main/a2/guide.md

Владелец или ответственный за публикацию загружает обновление и проверяет HTTP-ответы, текст и хэши. Сборщик сам ничего не публикует и не заменяет в удалённом репозитории. Сборки телефона и компьютера, настройка магазинов, выполненное внешнее дело и общий прогресс требуют своих доказательств. Маленькая панель Mac не выполняет команды и не читает другой терминал. Ручные карточки не передают данные автоматически между телефоном и компьютером.
