# Poly — продолжить дело в существующем проекте

Рабочий ИИ помогает подготовить короткую карточку: настоящая цель, сделанное, подтверждение, открытые вопросы и следующий шаг. Человек выбирает, что сохранить. Пароли, ключи и лишние личные сведения не включайте. Файл остаётся в выбранной рабочей папке; не добавляйте его в общий репозиторий без отдельного решения.

`continuation.py` работает локально через Python 3, без сети и установки пакетов. Он не запускает ИИ и не устанавливает вечную память. Сначала покажите человеку карточку и изменение инструкций:

```sh
python3 tools/continuation.py attach --project "/путь/к/проекту" --program codex --note "/путь/к/карточке.json"
```

Для Claude Code выберите `--program claude-code`. Карточка — JSON с `product: "Poly A2"`, `schema: 1`, непустыми `goal` и `nextUsefulStep`. Можно взять CONTINUATION.json из комплекта и заполнить известное. Укажите исходники внутри выбранной папки в `sources`, например `[{"path":"materials/notes.txt"}]`. Пустой шаблон не устанавливается. Если исходников нет, оставьте пустой список и явно запишите, что пока не проверено.

Без `--apply` ничего не записывается. После явного согласия человека повторите ту же команду с `--apply`. Если человек уже разрешил сохранить карточку и инструкции в выбранной папке, покажите подготовленный текст и примените его без повторного вопроса. Выберите программу текущей сессии: `codex` для Codex, `claude-code` для Claude Code. Инструмент сохранит карточку в `.poly-a2/CONTINUATION.json`, добавит короткую ссылку в AGENTS.md или CLAUDE.md и оставит резервные копии прежних файлов в `.poly-a2/backup-…`. При обновлении меняется только блок между метками Poly. Остальные инструкции сохраняются побайтно. Ссылки на файлы за пределами проекта и символические ссылки не принимаются.

Для продолжения в новой сессии:

```sh
python3 tools/continuation.py resume --project "/путь/к/проекту"
```

Проверьте, прочитал ли выбранный ИИ инструкции именно этой папки. Прочитайте текущие исходники, нужные для следующего шага. Выполните уже согласованное действие по этим источникам. Сохраните результат в согласованный файл и проверьте его содержимое. Согласие на обновление карточки и инструкций запрашивается отдельно. Уже порученное сохранение результата не требует повторного согласия. Отчёт `unchanged` подтверждает лишь совпадение байтов. При `changed` перечитайте изменённый источник и исправьте устаревшие выводы. При `missing` уточните факты, которые нельзя проверить. Перед сохранением обновлённой карточки покажите изменения человеку. Свежесть файла не доказывает правильность мысли или полезность результата. Если среда не читает такие инструкции, передайте карточку вручную и проверьте продолжение таким же способом.

Чтобы убрать подключение, после согласования удалите только блок между метками Poly в выбранном файле. Решение о сохранении или удалении приватной карточки принимает человек; инструмент ничего не удаляет автоматически.
