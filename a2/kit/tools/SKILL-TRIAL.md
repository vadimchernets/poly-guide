## Poly A2 — working AI contract

The AI prepares these files; the person chooses between readable A/B results. This local tool never calls a model, installs a skill or sends a file. All paths below are examples for the working AI. Inputs are agreed UTF-8 files, at most 2 MB each. Keep originals unchanged.

1. Agree success rules using QUALITY-SKILL.md. Choose three real tasks: an ordinary letter/plan, a difficult exception, and something unrelated where the skill should stay inactive. For each task, save one task and one source shared by both runs. Generate the ordinary answer and the answer with the skill in separate fresh conversations, with otherwise equal model/settings and task. Do not carry over the other answer. Obtain agreement before any external calls. If these conversations cannot be run, label saved examples as a local mechanism test; do not call them a with/without experiment.
2. Save complete actual answers, including failures. Record observed elapsed seconds only if measured; otherwise omit `seconds`. Record actual origin in `provenance`. Remove origin labels from answer headings without changing their substance. Prepare `cases.json` with exactly three entries in `cases`:

```json
{"cases":[{"kind":"ordinary","expected_use":"use","task":"/path/task1.txt","source":"/path/source1.txt","without":"/path/plain1.txt","with":"/path/skill1.txt","provenance":"actual model/session identifiers; or honest local-test origin"},{"kind":"edge","expected_use":"use","task":"/path/task2.txt","source":"/path/source2.txt","without":"/path/plain2.txt","with":"/path/skill2.txt","provenance":"actual origin"},{"kind":"unrelated","expected_use":"skip","task":"/path/task3.txt","source":"/path/source3.txt","without":"/path/plain3.txt","with":"/path/skill3.txt","provenance":"actual origin"}]}
```

Optional per-case `seconds` is `{"without":42.5,"with":51.2}`. Resolve relative input paths from the command's working folder. New output folders must not exist.

```sh
python3 tools/skill_trial.py prepare --cases /path/cases.json --rules /path/rules.json --output /path/new-trial
```

3. Give the reviewer only `BLIND/`: shared task, source, rules and two randomly assigned complete answers. Keep `PRIVATE/KEY.json` away from them until the decision; this is workflow separation, not encryption. Judge content against the task/source, not phrasing or length alone. Review both A and B using the full review schema in QUALITY-SKILL.md, with each answer's own hash and exact quotations. An unrelated criterion may be `unclear` with an empty quote and null lines. Separately record observed activation (`use`, `skip`, `unknown`) for both answers; do not infer it just because the expected setting says so.
4. Save a new decision file: `{"decider":"actual person or local-qa-not-owner","cases":[{"id":"1","choice":"A","reason":"reason based on the original task/source","activation":{"A":"unknown","B":"unknown"},"reviews":{"A":{"source_sha256":"...","checks":[]},"B":{"source_sha256":"...","checks":[]}}}]}`. Supply all three IDs (1, 2, 3), both full reviews, and choose `A`, `B`, `tie` or `undecided`. The AI may prepare the review, but must not invent a person's preference. Without their choice, save `undecided` and identify the actual reviewer.

```sh
python3 tools/skill_trial.py decide --folder /path/new-trial --decision /path/decision.json
python3 tools/skill_trial.py reveal --folder /path/new-trial
```

5. `decide` saves DECISION.json before `reveal` writes RESULT.json. Both check unchanged original files, original rules and blind copies. Repeated writes and reveal before decision fail with exit 2. Exit 0 proves file/quotation checks and ordering, not the truth of judgments or user preference. Compare disclosed origins, actual times if present, usefulness and activation across the three tasks. Keep ties and unknowns. Accept or reject suggested changes with the person. Change one rule only after a concrete observed failure, and retest on a new real input. Preserve the old trial.

Research basis: supplied Codex study item 3 (three real cases, fresh contexts, blind comparison, actual timing and applicability), Claude study (portable repeatable skill), orchestration ИТОГ (check actual answers and provenance). A local saved-example test does not prove skill effectiveness in independent AI sessions.
