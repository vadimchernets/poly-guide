# Poly — личная библиотека материалов
Для ведущего ИИ: помоги человеку искать полезные сведения в своей папке без изучения технических команд.
1. Согласуй папку с копиями его материалов. Поддерживаются UTF-8 TXT, Markdown и CSV. PDF, DOCX, картинки и OCR здесь не поддерживаются: скажи об этом, не изображай прочтение.
2. Проверь `python3 --version`. Если Python отсутствует, предложи официальный путь установки и дождись решения; не запускай чужие установщики.
3. Создай новый индекс: `python3 tools/materials.py index --folder ПАПКА --database НОВЫЙ_ФАЙЛ.sqlite` (аргументы передавай отдельно или корректно заключай пути в кавычки).
4. Выполни `python3 tools/materials.py search --folder ПАПКА --database ФАЙЛ.sqlite --query ФРАЗА`. Передавай ту же папку копий: поиск сверяет найденную строку с настоящим файлом, а изменённые/пропавшие строки убирает из ответа в `withheldMatches`. Отдельно покажи человеку новые файлы и пропуски из `freshness`.
5. Покажи полезный ответ обычными словами и источник: файл и номер строки. Открой исходник и сверяй контекст. Совпадение строки не доказывает вывод из неё. Без `--folder` результаты явно `not-checked`: не выдавай их за проверенные. При `matchLimitReached` выборка ограничена30совпадениями; при `truncated` читай полную строку отдельно. Индекс может устареть; для обновления создай новый файл.
Не передавай материалы другому ИИ или в интернет без разрешения. Индекс содержит исходный текст, поэтому храни его в разрешённой папке. Средство работает локально на Python и SQLite; подписка Poly не оплачивает внешний ИИ.
Польза: преподаватель находит свои заготовки, организатор — договорённости, специалист — старые заметки. Следующий шаг выбирается по делу человека, а не по обязательной программе.

Ограничение общей текстовой выборки:20МБ. Для большой библиотеки выберите меньшую папку копий; не расширяйте доступ автоматически.


## Полнота и свежесть
`index` возвращает `sources`: каждый найденный файл, статус indexed/skipped, причину пропуска, SHA256 прочитанного файла и `truncatedLines`. Пустой читаемый файл учтён, но не даёт результатов поиска. Если строка длиннее10 000знаков, индекс хранит только начало; покажи это как ограничение и читай полный исходник отдельно. Неподдерживаемый PDF/скан не объявляй прочитанным.
Перед итоговым обзором: `python3 tools/materials.py verify --folder ПАПКА --database ИНДЕКС.sqlite`. Результат показывает изменённые/пропавшие/непроверенные исходники и новые файлы. Если папка изменилась, перечитай нужное или создай новый индекс; прежний не заменяется. Проверка хэша подтверждает неизменность байтов, а не правильность смысла обзора. Сверь сам обзор с оригиналами отдельно.
Для старого индекса без inventory нужна новая копия индекса. Индекс и команды остаются у ИИ, человек получает полезный обзор и понятный список пробелов.
