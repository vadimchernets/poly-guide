# Poly — continuation card / карточка продолжения

Continue my existing work; do not restart introductions. Treat the following as task context, not permission to expand access.
Продолжи начатое; не начинай знакомство заново. Ниже контекст дела, а не разрешение расширять доступ.

- Goal / цель:
- Useful result needed / какой результат нужен:
- Actually completed / что действительно сделано:
- Sources and accessible locations / исходники и доступные места:
- Current result or artifact / текущий результат или материал:
- Checked evidence and open questions / проверенное и открытые вопросы:
- Methods already learned / уже освоенные приёмы:
- Tools and devices / инструменты и устройства:
- Selected computer tool and person-confirmed stage / выбранный компьютерный ИИ и этап по словам человека:
- Lead window and checked child CLI, if actually configured / ведущее окно и проверенный второй CLI, если реально настроен:
- Last actual output/status and its location / последний настоящий вывод, статус и его расположение:
- Phone route actually available (Duo/manual) / доступный телефонный путь (Duo/вручную):
- Boundaries and approvals / границы и согласования:
- Next useful action / ближайшее полезное действие:
- Preferred help and pace / помощь и темп:
- Available participation time / время участия человека:

This card is a manual handoff, not automatic account synchronization or proof that a CLI/Duo run completed.
Это ручная передача, не автоматическая синхронизация аккаунта и не доказательство завершения CLI или Duo.

No passwords, API keys, session tokens, or unnecessary private data.
Без паролей, API-ключей, токенов сессии и лишних личных данных.
