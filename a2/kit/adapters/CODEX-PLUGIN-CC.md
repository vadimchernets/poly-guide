# Poly — codex-plugin-cc

## en — Poly — Codex inside Claude Code

Open Claude Code. You also need Codex and Node.js 18.18 or newer.

Paste these lines into Claude Code, one at a time.

```text
/plugin marketplace add openai/codex-plugin-cc
/plugin install codex@openai-codex
/reload-plugins
/codex:setup
```

If asked to sign in, use the command below. Choose your ChatGPT account. Codex usage limits apply. API use has separate billing.

```text
!codex login
```

Ask Codex to check one small change. Compare its answer with your files.

```text
/codex:review --background
/codex:status
/codex:result
```

The commands match the author’s guide.

[Author’s guide](https://github.com/openai/codex-plugin-cc#install)
