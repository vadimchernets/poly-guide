# Poly — второй ИИ в рабочем окне

Ведущий Claude Code запускает этот адаптер с `--provider codex`; ведущий Codex — с `--provider claude-code`. В обоих случаях результат печатается в его же окно. Используется существующий вход через подписку; отдельный API не подключается. Python 3 и соответствующий CLI должны уже быть установлены.

1. Скопируйте папку `adapters` в согласованную рабочую папку. Настройки и инструкции человека не заменяются. Это переносимый адаптер, глобальная установка не требуется.
2. `python3 adapters/poly_second.py doctor --provider codex` (или `claude-code`). Без флагов это только версия и вход, не готовность. Для полной проверки после разрешения отправки маленького арифметического вопроса: `python3 adapters/poly_second.py doctor --provider codex --check --allow-network`. JSON содержит этапы installed → subscriptionLogin → functionalRequestPassed → ready; ready=true только после настоящего ответа с контрольным числом. Вставьте JSON в «Проверить готовность на компьютере» в Poly. Это отчёт о проверенной среде, не живая связь и не гарантия будущих ответов. Ключи и полный ответ авторизации не выводятся.
3. Подготовьте `review-task.txt` с разрешёнными исходными данными и вопросом. Не включайте пароли или закрытые данные без решения человека.
4. `python3 adapters/poly_second.py review --provider codex --task-file review-task.txt --allow-network`
5. Полученный `response` — настоящий вывод второго ИИ. Ведущий сравнивает его с оригиналами, исправляет результат и отдельно показывает пределы проверки. Повторите на другом входе перед использованием как постоянной схемы.

Задание передаётся через stdin, вывод не исполняется. Claude работает без инструментов и пользовательских настроек; Codex — в read-only режиме и временной рабочей папке. Read-only у Codex ограничивает запись, но не является изоляцией чтения файлов компьютера. Временная папка не отменяет этот доступ; используйте только разрешённую среду и данные. Диагностика canAttemptTask означает лишь установленный CLI и вход, а не выполненную задачу. Это не гарантирует истинность текста второго ИИ. Доступ к другому сервису не появляется от первой подписки. Недоступность/лимит останавливают запуск без API fallback.

Реальные запуски требуют разрешения на конкретный текст. Проверки адаптера на поддельных дочерних CLI не заменяют их. Поддержаны только Claude Code → Codex и Codex → Claude Code при установленном CLI и отдельном подписочном входе в каждый сервис. Gemini, Meta AI, DeepSeek и Grok в этом адаптере не подключены; Poly Duo на поддерживаемом телефоне — отдельный маршрут.
