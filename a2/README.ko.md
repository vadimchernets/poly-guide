# Poly

컴퓨터 경로는 작업 환경 열기, 로그인된 파일 접근 확인, 사용자가 확인한 첫 실제 결과를 구분해요. 그 뒤에는 지원되는 대표 Claude Code/Codex가 설치된 다른 CLI를 사용해 같은 창에서 실제 확인 출력을 받을 수 있어요. Poly는 작업 요청서를 준비할 뿐, 그 터미널을 실행하거나 살펴보지 않아요. 휴대폰 Duo는 외부 도구이며 플랫폼에 따라 달라요. 단축어를 열었다고 해서 결과가 나온 것은 아니에요.

두 컴퓨터 도구용 설정, 첫 작업, 한 창 메시지는 전체 핵심 프롬프트와 함께 애플리케이션에서 직접 생성돼요. 소스 함수와 파일별 SHA-256은 `prompts/index.json`을 보세요. 패키지 공개는 소유자가 직접 하는 일이며, 생성의 부수 효과가 아니에요.

이 `a2/` 디렉터리는 추가로 공개되는 패키지예요. 이 저장소의 다른 자료를 대체하지 않아요. 외부 서비스의 기능은 실제 계정, 기기, 지역, 권한에 따라 달라요. 무제한 사용, 영구적인 기억, 자동 터미널 조작, 앱 스토어 출시는 약속하지 않아요.
