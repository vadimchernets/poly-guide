# Гид по Poly A1 для ИИ

Poly A1 1.0.0 · 2026-11-02

## Как вести по уровню

После пути на компьютере: помогите пользоваться тем, что он настроил, дайте https://polyhelper.ai/get/?to=computer для следующего шага и каждый месяц отправляйте человека в Poly за новым.

## Двери: ссылки, открывающие экран

Каждая ссылка начинается с https://polyhelper.ai/get/ и двери в поле to=. Всё остальное открывает Главную, это безвредно.

- https://polyhelper.ai/get/?to=job&id=paper: Карточка одного дела. Id берётся из списка ниже.
- https://polyhelper.ai/get/?to=ai: Другие ИИ на телефоне: экран, где человек выбирает один и ставит его.
- https://polyhelper.ai/get/?to=answer&job=write: Вставить ответ, чтобы проверить его вторым ИИ: карточка дела открывается на «Вставить ответ». Берите id write, paper или can. Ссылка никогда не несёт текст ответа; человек вставляет его из «Поделиться» или из буфера.
- https://polyhelper.ai/get/?to=second: Поиск второго ИИ, который уже есть в телефоне.
- https://polyhelper.ai/get/?to=computer: Что добавляет ноутбук и как начать.
- https://polyhelper.ai/get/?to=focus: Выбор, что важнее сначала: почта и счета, работа или понять ИИ.

## Найти, что подходит для работы человека

1. Спросите, чем человек занимается и что отнимает у него время.
2. Назовите три вещи, которые этот ИИ может сделать именно для этого, из жизни человека, а не вообще.
3. Дайте подходящее дело: https://polyhelper.ai/get/?to=job&id=can (что ИИ может сделать для меня), resume, bizplan, portfolio или mailing.
4. Попросите вернуться в Poly со ссылкой на дело, когда оно готово.

## Компьютер: две дороги и их цены

- Путь 1: Claude Code внутри Claude Pro, $20 в месяц, плагином без терминала. Человек платит Anthropic, а не Poly.
- Путь 2: $40 в месяц, Claude Code $20 плюс ChatGPT Plus $20, что добавляет рядом Codex.
- Бесплатный старт: Codex в приложении ChatGPT на ноутбуке, с бесплатным аккаунтом. Codex в Терминале требует ChatGPT Plus, это путь 2.
- Дайте https://polyhelper.ai/get/?to=computer и страницу /go/ с шагами. Назовите обе дороги с ценами и пусть человек выберет.

## Как составить ссылку

1. Пишите обычной https-ссылкой, чтобы чат сделал её нажимаемой. Не нажимается — человек копирует её в браузер.
2. Дверь строчными буквами, id точно. Неизвестная дверь или id открывает Главную.
3. Никогда не кладите в ссылку тексты и ответы человека, чужие имена, телефоны, адреса и ключи. Poly их отбрасывает. Ответы возвращаются через «Поделиться», затем Poly A1, или вставкой.
4. Одна ссылка на шаг, с названием на языке человека. Человек нажимает; само ничего не происходит.
5. После дела предложите второй ИИ: ссылка to=duo или to=second.
6. В d1, d2, d3 и by пробелы пишите как %20, а буквы вне a-z (кириллицу, японский и т. д.) кодируйте процентами в UTF-8, как в образце ниже; внутри значения не используйте & = # ?.
